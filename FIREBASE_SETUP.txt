ANTIC R.O SYSTEM CRM — FIREBASE SETUP (REPAIRED PACKAGE)

1. Upload ALL files from this folder to the root of your GitHub Pages repository.
2. Firebase Console > Project settings > Your apps > Web app > SDK setup and configuration > Config.
3. In the CRM, open Settings > Configure Cloud. Paste the complete firebaseConfig JSON object and click Save & Connect.
4. In Firebase Console > Authentication > Sign-in method, enable Email/Password.
5. In Authentication, create an account (or use CRM Create Admin Account once).
6. Create/enable Firestore Database. Publish the owner-only rules from firestore.rules.
7. Log in to CRM. Settings > Firebase Test should pass.

This repaired package loads Firebase compat SDKs, reads the saved config, initializes Firebase App/Auth/Firestore, and reacts to sign-in state. Your actual Firebase project config is NOT included; you must add it in the CRM. Firebase web config is client-side configuration, not a service-account private key.

DATA NOTE: Existing CRM records in this browser remain in localStorage. Cloud data is scoped to the signed-in Firebase UID. Take a backup before testing or switching accounts.

If login fails, check that Email/Password is enabled, the correct Firebase config was entered, and Firestore rules are published. Never use public read/write rules or share a service-account private key.
