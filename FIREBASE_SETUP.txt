ANTIC R.O SYSTEM CRM — FIREBASE CONNECTED BUILD

Firebase Web App config for project antic-ro-system-crm is prefilled in index.html.
The CRM loads Firebase v10 COMPAT SDK files from Google's CDN and uses Firebase Authentication + Cloud Firestore.

ONE-TIME FIREBASE CONSOLE SETUP:
1. Firebase Console > Authentication > Get started > Sign-in method > enable Email/Password.
2. Firebase Console > Firestore Database > Create database (production mode is fine).
3. In Firestore > Rules, publish the contents of firestore.rules from this ZIP.
4. Upload/replace the ZIP contents in the GitHub Pages repository. Keep index.html and all assets together.
5. Open the published CRM with internet access. It should show Firebase ready and prompt for login.
6. Choose Create Admin Account once, using your email and a password of at least 6 characters. Then use Login & Sync.
7. After login, use Settings > Firebase Test to verify Firestore read/write/delete permissions.

IMPORTANT:
- Firebase config is client-side web-app configuration, not a service-account private key.
- Never publish or share a Firebase Service Account private key.
- Do NOT use public read/write Firestore rules. The included rules restrict each signed-in user to their own UID path.
- First successful login with an empty cloud account uploads the CRM data currently stored in that browser. Keep a backup before switching devices/accounts.
- Cloud sync requires internet access. The CRM may continue in local mode if Firebase's CDN or network is unavailable.
- Firebase config is also available in Settings > Configure Cloud if you need to change it later.
